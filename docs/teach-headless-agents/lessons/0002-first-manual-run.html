درس قبل · چیت‌شیت CLI

درس ۲: اولین اجرای دستی (یک use case)

گام‌به‌گام — یکی از سه CLI را انتخاب کن

گام ۰ — آماده‌سازی

cd E:\barber\beauty-saloon-api
dotnet build BarberSalon.slnx
dotnet test

هر دو باید سبز باشند (placeholder tests کافی است).

گام ۱ — DryRun (فقط نگاه)

.\run-backend-cycle.ps1 -DryRun

باید ببینی: GetActiveSalonServices انتخاب شد و دوباره pending شد.

گام ۲ — Enrich (اسکریپت)

یک بار بدون DryRun اجرا کن و بعد از خط Enrich Ctrl+C بزن — یا فقط این را دستی بزن:

.\run-backend-cycle.ps1

فایل .agents\state\current-prompt.txt باید پر شود.

گام ۳ — Inject (یکی را انتخاب کن)

A) Cline

توجه: خط $p = ... خروجی چاپ نمی‌کند — فقط حافظه را پر می‌کند. بعد باید cline را بزنی.

cd E:\barber\beauty-saloon-api
$p = Get-Content .agents\state\current-prompt.txt -Raw
Write-Host "loaded chars:" $p.Length
cline -c E:\barber\beauty-saloon-api -t 1500 "$p"

B) OpenCode

cd E:\barber\beauty-saloon-api
Get-Content .agents\state\current-prompt.txt -Raw | opencode run --auto --dir E:\barber\beauty-saloon-api

C) Antigravity (agy)

cd E:\barber\beauty-saloon-api
$p = Get-Content .agents\state\current-prompt.txt -Raw
agy --print $p --dangerously-skip-permissions --mode accept-edits --add-dir E:\barber\beauty-saloon-api

گام ۴ — Verify (خودت)

dotnet test E:\barber\beauty-saloon-api\

سبز = این iteration موفق. قرمز = دوباره Inject با «fix test failures».

گام ۵ — بعداً: حلقه کامل

وقتی Inject را داخل اسکریپت wire کردی، فقط می‌زنی:

.\run-backend-cycle.ps1

و تا تمام شدن queue می‌چرخد.
