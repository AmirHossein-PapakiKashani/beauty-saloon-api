درس ۳: Inject، Wire، حلقه، و -Once

همان پنج گام — فقط دیگر دستی نیست

تشبیه رستوران

صف (queue.json) = لیست سفارش‌ها
Select = گارسون سفارش بعدی را برمی‌دارد
Enrich = دستور پخت را روی کاغذ می‌نویسد (current-prompt.txt)
Inject = کاغذ را به آشپز می‌دهد
Verify = کنترل کیفیت (مزه = dotnet test)
Close = سفارش را تیک می‌زند (صف آپدیت)

Inject یعنی چه؟

تزریق پرامپت به agent. یعنی محتوای current-prompt.txt را به‌عنوان مأموریت به Cline/OpenCode/AGY بدهی تا کد بزند.

قبلاً تو این کار را دستی می‌کردی. الان اسکریپت همان کار را صدا می‌زند.

Wire یعنی چه؟

سیم‌کشی / وصل کردن. قبلاً جای Inject فقط یک پیام stub بود («اینجا CLI را بگذار»). Wire کردن = آن بخش خالی را با فراخوانی واقعی cline / opencode / agy پر کردیم.

حلقه چیست؟

while هنوز pending هست:
    Select → Enrich → Inject → Verify → Close
    (اگر -Once: بعد از یک دور بایست)

فایل: run-backend-cycle.ps1 — این «مدیر کارگاه» است، نه خود LLM.

-Agent cline -Once چه می‌کند؟

  • -Agent cline = آشپز این دور Cline باشد (نه OpenCode، نه AGY)
  • -Once = فقط یک use case؛ بعد بایست (برای اولین اجرای خودکار امن‌تر است)
.\run-backend-cycle.ps1 -Agent cline -Once

موازی چند agent؟

روی یک پوشهٔ مشترک همزمان = خطر تداخل فایل. الگوی درست: هر agent یک worktree/شاخه جدا + use caseهای بدون وابستگی مشترک.

Inject کدام کار است؟

الف) نوشتن پرامپت در فایل

ب) دادن پرامپت به CLI برای کد زدن

ج) اجرای dotnet test

پاسخ

ب — الف = Enrich، ج = Verify

سؤال داری؟ از agent بپرس.
