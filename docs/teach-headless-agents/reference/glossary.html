واژه‌نامه

Orchestrator
اسکریپت PowerShell — تصمیم‌گیرنده؛ LLM نیست.
Use case
یک قابلیت کامل با تست — مثلاً GetActiveSalonServices.
Inject
دادن current-prompt.txt به CLI headless برای نوشتن کد.
Wire
وصل کردن یک بخش خالی (stub) به پیاده‌سازی واقعی — مثلاً صدا زدن cline.
Loop / حلقه
تکرار Select→Enrich→Inject→Verify→Close تا صف خالی شود.
-Once
فقط یک use case اجرا کن، بعد بایست.
-Agent
کدام CLI آشپز باشد: cline | opencode | agy.
Verify gate
dotnet test — تنها معیار «تمام شد».
Headless
بدون UI؛ agent از terminal با auto-approve کار می‌کند.
